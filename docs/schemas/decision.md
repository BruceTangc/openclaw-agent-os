# Decision Model

A decision should conceptually contain:
- objective
- candidate action
- expected benefit
- risk
- reversibility
- confidence
- authority level
- evidence
- decision
- reason

Decision outcomes:
IGNORE / OBSERVE / QUEUE / SUGGEST / PREPARE / EXECUTE / ASK / ESCALATE
(另: NOOP≈IGNORE, INFORM≈SUGGEST, ACT≈EXECUTE, DENY 由 Permission-Security 输出)
