# Multi-Agent Learning Protocol v2

Agent OS is multi-agent native and orchestration-free.

OpenClaw owns agent creation, bindings, routing, sessions, subagents, A2A, task flow and execution. Agent OS consumes native provenance.

## Identity
Never infer root ownership solely from agentId `main`. Resolve agent/session/requester/parent/root relationships from native context. Permanent configured agents can own durable AGENT experience. Ephemeral subagents contribute evidence but default durable ownership to requester/owning permanent agent.

## Verification
Verify child task, delegation acceptance/integration, and final user outcome separately. Local PASS != global PASS.

## Learning isolation
Do not share experience merely because agents collaborated. AGENT lessons remain agent-scoped until evidence supports TEAM promotion. TEAM lessons require governance before SHARED promotion. Prevent coding/domain-specific lessons from contaminating unrelated agents.

## Team
TEAM is a learning scope, not a second orchestration runtime. If OpenClaw exposes native team identity use it; otherwise adapter may derive a stable team scope from explicit configured membership/provenance without taking over scheduling.
